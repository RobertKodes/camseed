# camseed

Point the camera (or drop a still). Hash the frame. Get a Solana-ish address out.

Webcam / image → downsampled pixels → SHA-256 → PDA-style address preview.
The input is light — not another fee/slot costume. Sibling to drawseed (ink), different sense.
